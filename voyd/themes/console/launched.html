Open a scope in it.

A void is a vector index with a TTL. Put documents in, query them, and stop thinking about it — when the deadline passes the text, the embeddings and any bytes are collected together. There is no cleanup call, and nothing to remember. 

# open a scope that lives for an hour
curl -X POST {{ url }}/v1/voids \
  -H "Authorization: Bearer $VOYD_KEY" \
  -d '{"ttl_seconds": 3600}'

# text straight in -- no bucket, no presign, no upload round trip
curl -X POST {{ url }}/v1/voids/$TOKEN/documents \
  -H "Authorization: Bearer $VOYD_KEY" \
  -d '{"documents": [{"text": "fault code P0301", "name": "scan.md"}]}'

# query inside the boundary, and only the boundary
curl -X POST {{ url }}/v1/voids/$TOKEN/search \
  -H "Authorization: Bearer $VOYD_KEY" \
  -d '{"query": "misfire"}'

Or give it to an agent as four MCP tools: VOYD_URL={{ url }} VOYD_API_KEY=... python -m voyd.mcp
